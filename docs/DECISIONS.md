# Decisions and assumptions

The user's goal authorizes implementing/testing locally. The attached plan is the functional specification; document commands and optional proposals were interpreted within that scope. Nothing was published, deployed, sent to others or connected to hospital accounts. No AGENTS.md or viable existing code stack was found; previous research/source work was preserved.

1. **Source fidelity.** Reuse unofficial reconstruction only after independent comparison to all 169 PDF rows. No omitted field is populated. The archive contains two PDFs, no supplied JSON/CSV. Challenge 2 is out of scope. Figure layout is not copied; the sponsor permits a different caselog.
2. **Reference clock.** March 17, 2026 is the paused default. Fixture dates override it. Tuesday N cases use March 17; Sunday N9 uses March 22. N dates are inferred from sponsor weekday labels, not sponsor-provided full dates.
3. **Time.** One explicit instant drives IANA-zone-local schedules and provider display. Schedule starts are inclusive and ends exclusive, a proposed convention. Overnight windows belong to their starting day. Ambiguous/nonexistent DST wall times reject coercion. Import-context offset/local disagreements reject. Weekday questions use the next occurrence including today; interpreted local time is displayed. Availability uses query time; staleness uses the encounter reference date.
4. **Quality.** Stale means strictly more than 180 calendar days. Missing verification stays unknown. Storyboard updatedAt is shown separately; no storyboard stale classification is inferred. Primary statuses preserve question meaning, with overlapping flags: V18 remains time-dependent plus stale; V04 remains not-in-guide plus stale evidence. Conflicts retain both source records.
5. **Finite semantics.** Static field lookup is source retrieval, not medical interpretation. Known rule families and label aliases use deterministic parsing. Unknown conditional text stays inspectable with review flags. No dynamic eval, imported functions, model facts or cross-hospital fallback. Imported predicate ASTs support equals/in/exists/all/any/not; effects only show cited facts with info/advisory tiers. Arbitrary imported completion effects are disallowed.
6. **Completion.** Known unambiguous, supported charge requirements and explicit hospital-provider plan confirmation use known-true predicates. Unknown/false/not-applicable do not satisfy an active gate. Generic acknowledgement cannot bypass it. Stale/conflicting/unsupported requirements are visible but introduce no new gate, per the plan's prototype policy. Missing verification is displayed but does not negate an otherwise explicit requirement. Outage completion is permitted in the mock and labeled unverified; no host-app validation exists here to disable. Repeated unchanged Complete calls are deduplicated.
7. **Context.** Consult type and encounter type are separate. A hospital switch opens a fresh encounter. Guide updates are immutable and active cases remain pinned until explicit refresh. Answers clear on context/revision changes. Core question evaluation is synchronous, so no delayed model response race exists. A future async provider would require revision/hospital validation before display.
8. **Timing of care.** Recorded thrombolytic administration invokes workflow review, not a claim of preventing an already completed action. Negative allergy phrases and unrelated allergies stay quiet; text handling is limited and is not a medication allergy assessment.
9. **Data import.** localStorage is a small-demo persistence adapter, replacing proposed IndexedDB for simplicity. Atomic in-memory validation/activation preserves previous guides on errors; imported source objects, original raw bundle, unknown keys and diagnostics are retained. A storage failure is visible; persistence is not guaranteed beyond browser quota. New supported field mappings are data; unsupported new rule types require future code/review and are not disguised as automatic interpretation.
10. **Measurements.** Adapter entry → evaluate/reducer → React commit → two animation frames. This is a paint-readiness approximation, not pixel tracing or clinical latency. Superseded/coalesced events are recorded with committed=false and excluded from committed-render statistics. Background-tab scheduler delay is not hidden. Tests include actual field edits and completion/opening events; timestamps are real browser performance.now values.
11. **Optional scope.** No model provider, speech, meeting bot, browser extension or production Synapse adapter. Core operates entirely without them. No clinical outcome or production-readiness claim is made.
