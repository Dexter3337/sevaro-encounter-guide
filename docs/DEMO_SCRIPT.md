# Five-minute reproducible demo

Start using README.md. Open Demo controls and click Reset demo data. All times are simulated, explicit and paused. Use the seven seed hospitals for sponsor scenarios; imported unfamiliar guides are additional fictional data.

1. **0:00–1:00 · Useful guidance.** Default hospital is SYN-006 at Tue 19:30 Central. Open Imaging; set LVO Yes. Read the ED-provider transfer action. Expand evidence: PDF p9 and verification date are visible. In Demo controls set instant `2026-03-17T17:00:00Z` (12:00 Central) and Apply clock. The same source now selects the EVT activation branch. Provider display zone changes never alter that hospital-local decision.
2. **1:00–2:00 · Restraint and uncertainty.** Launch N8; Allergies `none` yields no guidance. Launch V12; inspect the CT holding bay guide versus patient-room storyboard, including their distinct dates. Ask `Who covers pediatric neurology?` at SYN-002: absent field evidence, no another-site answer. Launch V18: pharmacy hours remain undefined, with stale and time-dependent flags together. V04 and V13 contrast unknown Friday EEG availability with the listed but stale Thursday window.
3. **2:00–2:45 · Completion.** Launch N5. Click Complete: blocked. Record Encounter charge → Yes, then Complete: success. This records a statement rather than posting a charge. Launch N7 for explicit hospital-provider plan confirmation. Acknowledging guidance cannot satisfy either requirement.
4. **2:45–4:00 · Add unfamiliar data.** Guide library → upload/paste `data/holdout/unfamiliar-hospitals.json` → Preview → inspect interpretations → Activate. Choose Harbor Lantern (ORBIT-91). Set explicit clock `2026-03-18T02:30:00Z` (Tue 19:30 Pacific), Imaging → LVO Yes. The fictional Coast Center transfer actor/destination comes from imported data. Ask `What is the interpreter connection procedure?`: SYN-778 appears with the new field's source. Intake → Interpreter needed → enter `Yes`: the imported declarative mapping proactively displays the same source. Explore Transport clearance: retained but flagged for review. No rebuild/restart or rule authoring occurred during this demo.
5. **4:00–5:00 · Evidence.** Evaluation → Run 29 sponsor cases. Inspect expected/actual meanings, status and source IDs; export JSON/CSV. Open measurements: actual browser edits are measured separately from engine-only timings. Download audit/latency. Use `reports/TEST_RESULTS.md` for the separately measured acceptance/browser run and limits.

Optional failure demonstration: enable guide outage in Demo controls. Continue editing the caselog. Guidance unavailable is visible; questions do not fabricate source answers. Completion while unavailable is explicitly unverified. Disable outage to resume source-backed guidance.

CSV demo: paste/upload `data/holdout/mapped-import.csv`, select CSV, map Site Code→hospitalId, Site Name→name, Zone→timezone, Rule Label→field, Original Text→raw, Checked→lastVerified, Revision→version. Preview and activate; ask the new interpreter field at CSV-NEW.

After importing a second version of an existing hospital, the active encounter remains pinned until you use Refresh. Reload retains imported versions and draft state. Reset affects only prototype storage. No real patient data, microphone, production account or paid API is needed.
